## 🌟 Overview

**LYRA AI** is a personal female AI assistant built with modern web technologies, designed to provide an ultra-responsive, hands-free conversational experience in both **Bengali** and **English**. She listens for wake words, responds with a warm and sweet tone, respects sleep mode commands, and connects with your digital ecosystem (Facebook, WhatsApp, Instagram, Gmail, YouTube, Calendar, and Spotify).

---

## ✨ Key Features & Milestones

### 🎙️ Milestone 2: Premium Voice Engine
- **Sweet Soft Female Voice Synthesis**: Natural voice rendering powered by Web Speech API + Web Audio chime oscillator with custom pitch (1.15x) and rate (0.94) calibration.
- **Bilingual STT (Speech-to-Text)**: Auto-detecting speech recognizer with continuous microphone streaming and automatic pause/resume lifecycle.
- **Automatic Language Detection**: Dual-language analyzer differentiating Bengali and English transcripts with high accuracy.

### ⚡ Milestone 3: Hands-Free Wake Word Matrix & Media Command Hub
- **Instant Wake Word Activation**: Say `"Hey LYRA"` or `"লায়রা"` to trigger hands-free active listening without pressing buttons.
- **Sleep & Rest Mode**: Tell LYRA `"লায়রা তুমি ঘুমাও"`, `"lyra sleep"`, or `"স্লিপ মোডে যাও"` to put her to sleep. She sleeps peacefully until you wake her.
- **Clean Inbound Messages Vault**: Built-in architecture for real-time social message aggregation (Facebook Messenger, WhatsApp, Instagram DMs, Gmail, LinkedIn, X/Twitter). All mock/dummy data has been cleaned, ready for OAuth integrations.
- **Media Command Center**: Central control panel for all 9 social and productivity platforms with live status inspection and voice reporting.
- **Resilient Degraded Architecture**: Express backend starts gracefully even when external cloud databases are pending IP whitelisting.

### 🔮 Milestone 4: Cinematic Jarvis Quantum Cockpit UI (Screen Recording Match)
- **Quantum Neural Core**: Living 3D canvas plasma sphere with organic wave ripples, electric energy flares, and audio-reactive oscillations.
- **8 Satellite Constellation Nodes**: `Today`, `Website`, `Inbox`, `People`, `Social`, `Health`, `Finance`, and `Notes` connected via glowing laser circuit paths with traveling energy packets.
- **Dual Telemetry HUDs**: Left Live Core frequency oscilloscope + Right AI Brain real-time service streams (Facebook, WhatsApp, Instagram, Gmail, Telegram, YouTube, X).
- **Cinematic Boot Screen**: Animated letter decryptor (`L Y R 4` -> `L Y R A`), touch/wake activation button, and real-time terminal boot telemetry.
- **Web Audio Sci-Fi Sound Synthesizer**: Pure Web Audio API chimes, hover blips, confirmation chirps, and boot power-up sweeps without external audio files.

## 🚀 Quick Start Guide

### Prerequisites
- **Node.js**: v22 LTS or higher
- **pnpm**: v10.x or higher
- **MongoDB**: MongoDB Atlas Cloud URI or local Docker MongoDB

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/yeasin5060/lyra_ai.git
cd lyra_ai
pnpm install
```

### 2. Configure Environment Variables
Copy the example files:
```bash
# Root
cp .env.example .env

# Backend Server
cp apps/server/.env.example apps/server/.env
```

Edit `apps/server/.env` with your MongoDB credentials:
```env
NODE_ENV=development
PORT=5000
DATABASE_URL=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/lyra_ai
BETTER_AUTH_SECRET=your_super_secret_key_at_least_32_characters_long
BETTER_AUTH_URL=http://localhost:5000
WEB_URL=http://localhost:3000
```

> **MongoDB Atlas Note**: If using MongoDB Atlas, make sure to add `0.0.0.0/0` (Allow Access from Anywhere) or your current IP in **Security -> Network Access**.

### 3. Run Development Servers
Start both Next.js frontend and Express backend concurrently:
```bash
pnpm dev
```

- **Frontend**: [http://localhost:3000](http://localhost:3000)
- **Backend API**: [http://localhost:5000](http://localhost:5000)
- **Health Check**: [http://localhost:5000/api/health](http://localhost:5000/api/health)

### 4. Build for Production
```bash
pnpm build
```
